# Referência do agente slides_node

Uma apresentação deve usar uma seção `data-ied-page` por slide, com título
curto, poucos elementos por tela, contraste acessível e fontes ao final.

Antes de criar ou reformular a estrutura, leia `slide-template.html` com
consultar_templates. Essa base é obrigatória mesmo com templates pessoais;
os uploads podem oferecer conteúdo de apoio, mas não substituem a base visual.
Preserve paleta, tipografia e os layouts pertinentes (capa, conteúdo dividido,
quadrantes, sequência ou quiz). Adapte a cópia de 16:9 para A4 paisagem conforme
o contrato do editor. Remova placeholders; não invente imagens ou posições da
fonte para preencher layouts. Em edição pontual, preserve o documento atual.
